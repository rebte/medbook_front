# 🏥 МедБук — Онлайн запис до лікарів

Простий адаптивний сайт для швидкого онлайн-запису до лікарів. Проект створено як навчальна робота для дисципліни "WEB-орієнтовані технології. Backend розробки".

---

## ✨ Основні можливості

- Пошук лікарів за спеціальністю
- Перегляд спеціалістів з фото, рейтингом і відгуками
- Відкритий розклад та доступні часові слоти
- Онлайн-запис в кілька кроків
- Підтвердження запису і повідомлення
- Адаптивний дизайн для телефону, планшета і десктопу

---

## 🛠 Технології

- HTML5
- CSS3 (Flexbox, Grid, медіа-запити)
- Vanilla JavaScript (ES6+)
- Git / GitHub

---

## 🚀 Як запустити

1. Клонуй репозиторій:
   ```bash
git clone https://github.com/rebte/medbook_front.git
cd medbook
```
2. Відкрий `index.html` у браузері або запусти локальний сервер:
   ```bash
python -m http.server 8000
```
3. Перейдіть на `http://localhost:8000`
